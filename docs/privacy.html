Privacy개인정보처리방침

Last updated: November 12, 2026마지막 수정: 2026년 11월 12일

The Woodada app doesn't collect anything about you. This website counts visits with Google Analytics so I can see how many people stop by and where from. Woodada 앱은 사용자에 대한 정보를 모으지 않아요. 이 홈페이지는 몇 명이 어디서 들어오는지 보려고 Google Analytics로 방문 통계를 내요.

The app앱

  • No accounts, no tracking, no usage statistics. 계정, 추적, 사용 통계가 없어요.
  • CPU and memory readings are used only to set the cat's speed and never leave your computer. CPU·메모리 사용률은 고양이 속도를 정하는 데만 쓰고, 내 컴퓨터 밖으로 보내지 않아요.
  • Your settings and collected skins are saved in a file on your computer only. 설정과 모은 스킨은 내 컴퓨터의 파일에만 저장돼요.
  • To check for updates, the app asks GitHub for the latest release when it starts and every 6 hours after that, and downloads new versions from GitHub. GitHub sees these requests like any other web request (your IP address and the app version). See the GitHub Privacy Statement. 업데이트를 확인하려고 켜질 때와 그 뒤 6시간마다 GitHub에 최신 버전을 묻고, 새 버전도 GitHub에서 받아요. 이때 GitHub는 일반 웹 요청처럼 IP 주소와 앱 버전을 받아요. 자세한 건 GitHub 개인정보 처리방침을 참고하세요.

This website홈페이지

  • Google Analytics. It records pages viewed, approximate location (country and city), device and browser, the site you came from, and clicks on the download buttons. It sets cookies to tell repeat visits apart. Google Analytics doesn't store IP addresses, and advertising features are turned off. Google Analytics. 본 페이지, 대략적인 위치(국가·도시), 기기와 브라우저, 어디서 들어왔는지, 다운로드 버튼 클릭을 기록해요. 다시 온 방문을 구분하려고 쿠키를 써요. Google Analytics는 IP 주소를 저장하지 않고, 광고 기능은 꺼 두었어요.
  • Visitors in Europe. If your browser's time zone is in Europe, Google Analytics isn't loaded at all. Visitors from the EEA, the UK and Switzerland who still reach it get no analytics cookies. 유럽 방문자. 브라우저 시간대가 유럽이면 Google Analytics를 아예 불러오지 않아요. 그래도 들어온 유럽(EEA)·영국·스위스 방문자에게는 분석용 쿠키를 저장하지 않아요.
  • Opting out. Use a content blocker or Google's opt-out browser add-on. 거부하기. 광고 차단기나 Google의 Analytics 차단 부가기능을 쓰면 통계에서 빠져요.
  • Hosting and fonts. The site is hosted on GitHub Pages and loads its fonts from jsDelivr. Both receive your IP address as part of serving the page. 호스팅과 글꼴. 홈페이지는 GitHub Pages에서 열리고 글꼴은 jsDelivr에서 받아요. 둘 다 페이지를 보내 주는 과정에서 IP 주소를 받아요.
  • Language choice. Saved in your browser only. 언어 선택. 내 브라우저에만 저장돼요.
